# Soru Havuzu Projesi — Çalışma Talimatları

Bu depoda çalışmaya başlamadan önce aşağıdaki dosyaları sırayla oku:

1. `docs/PROJECT_REQUIREMENTS.md`
2. `docs/DECISIONS.md`
3. `docs/ROADMAP.md`
4. `docs/CURRENT_STATUS.md`

## Bağlayıcı kurallar

- Kullanıcıdan açık onay alınmadan gereksinimleri değiştirme.
- Sistem yapay zekâ entegrasyonu içermeyecek.
- Ana teknoloji Django + PostgreSQL'dir.
- Uygulama önce yerel ve tek kullanıcılı çalışacak, daha sonra özel web ortamına taşınacak.
- Başka projeler veritabanına doğrudan bağlanmayacak; sürümlendirilmiş REST API kullanacak.
- Her geliştirme aşamasında testleri çalıştır ve sonucu bildir.
- İlgisiz kullanıcı değişikliklerini silme veya üzerine yazma.
- Çalışmaya `docs/CURRENT_STATUS.md` içindeki sıradaki aşamadan devam et.
